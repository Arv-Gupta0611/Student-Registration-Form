# Student Registration Form

A simple and responsive Student Registration Form built using HTML and CSS. This project provides a clean and user-friendly interface for collecting student details through a registration form.

## Features

- Student details input fields
- Roll number and student name
- Father's name and date of birth
- Mobile number and email
- Password field
- Gender selection using radio buttons
- Department selection using checkboxes
- Course selection using a dropdown menu
- Student photo upload option
- City and address fields
- Register button
- Clean and attractive UI design

## Technologies Used

- HTML5
- CSS3

This project was created to practice HTML form elements, table-based layouts, and CSS styling while building a student registration form.
